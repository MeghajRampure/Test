# Luma Interiors

A polished, responsive website template for a home interior detailing company. Luma Interiors presents a calm, premium service experience with warm editorial styling, clear service offerings, and a straightforward inquiry flow.

## Highlights

- Responsive, mobile-friendly landing page
- Hero section with prominent call to action
- Interior detailing service overview
- Brand and trust-focused “Our approach” section
- Client testimonial area
- Contact details and inquiry form with confirmation state
- Smooth in-page navigation and mobile menu

## Built with

- React
- Vite
- CSS
- Lucide React icons

## Run locally

Install dependencies if needed, then start the development server:

```bash
npm install
npm run dev
```

Create an optimized production build with:

```bash
npm run build
```

## Project structure

```text
src/
  main.jsx       # Page structure and interactions
  styles.css     # Responsive visual design
index.html       # Vite entry point
```

The brand name, service copy, contact information, and photography URLs are all placeholder content intended to be customized for the final business.
